# Mi primer sitio web HTML5 semántico

Trabajo académico en HTML5 sin CSS ni JavaScript.

## Archivos
- `index.html`: Curriculum Vitae, datos personales y perfil.
- `estudios.html`: educación y nivel académico.
- `intereses.html`: hobbies, video y música.
- `imagenes/`: ilustraciones en SVG.

## Antes de entregar
1. Sustituye todos los textos entre corchetes por tus datos reales.
2. Actualiza el correo y el enlace a tu perfil de GitHub.
3. Cambia las descripciones y los intereses para que sean verdaderamente tuyos.
4. Abre `index.html` en un navegador y prueba los enlaces entre páginas.
5. Sube toda la carpeta al repositorio público de GitHub y entrega el enlace de esa carpeta en Moodle.

No publiques dirección, teléfono ni documentos personales.
